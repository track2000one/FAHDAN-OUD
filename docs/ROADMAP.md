# خطة التنفيذ المعتمدة — فهدان للعود

## المرحلة 1 — الهيكل الأساسي (الإصدار 0.1.0)
- [x] إنشاء Monorepo بـ npm workspaces.
- [x] واجهة React/TypeScript/Vite متوافقة مع RTL والشاشات الصغيرة.
- [x] الصفحة الرئيسية، التصنيفات، البحث، الفرز، تفاصيل المنتج والأوزان والسلة التجريبية.
- [x] API بـ Express/TypeScript ومسارات عامة مع تحديد حقول الاستجابة.
- [x] مخطط Prisma/PostgreSQL للمنتجات والمتغيرات والموردين والمشتريات والمخزون والطلبات.
- [x] تسجيل دخول المالك JWT ومسار خاص لمؤشرات لوحة الإدارة.
- [x] بيانات عرض اختيارية وتحديد واضح أنها افتراضية.
- [ ] اختبار تكامل مباشر بعد تنزيل الحزم وتشغيل PostgreSQL (شبكة حزم npm غير متاحة أثناء الإعداد).

## المرحلة 2 — إدارة بيانات المنتجات الفعلية
- [ ] CRUD محمي للمنتجات والأصناف والأوزان والتصنيفات مع سجل تدقيق.
- [ ] رفع صور منتجات حقيقية وتخزينها في خدمة ملفات، فيديو تبخير إن توفر.
- [ ] تحقق من تكرار SKU والمنشأ والدرجة ومعالجة وصف المنتج.
- [ ] دعم وزن مستقل لكل قسم (جرام/ملليلتر/قطعة) دون افتراض أن البكج يقاس بالجرام.
- [ ] سياسات التسعير وخصم الكميات وإظهار السعر السابق عند تحقق شروط الخصم.

## المرحلة 3 — المخزون والمشتريات
- [ ] تسجيل الموردين ودفعات الشراء وتكلفة الوصول والمصاريف الموزعة.
- [ ] تقييد عمليات المخزون داخل معاملات قاعدة البيانات وبمفاتيح عدم التكرار.
- [ ] حجز الرصيد بمهلة مع انتهاء الحجز وتأكيد المبيعات بعد تحصيل آمن.
- [ ] خصم العينات والتالف والمرتجعات بإثبات حركة مخزون وسجل تدقيق.
- [ ] سياسة تكلفة مخزون معتمدة (مثل FIFO) وتقارير تكاليف دقيقة.

## المرحلة 4 — المعاملات التجارية
- [ ] إتمام الطلب وإدخال العنوان، والتحقق من المخزون والأسعار من الخادم فقط.
- [ ] بوابة دفع مُرخّصة، Webhook موثّق وتأكيد الدفع ومنع الطلبات المكررة.
- [ ] شركات الشحن، التعرفة حسب المدينة والأوزان وأرقام التتبع.
- [ ] السياسات النظامية والشروط والخصوصية والموافقات اللازمة.
- [ ] مراجعة متطلبات الفوترة الإلكترونية والضريبة بحسب التزام المنشأة.

## المرحلة 5 — الإدارة والمالية والإطلاق
- [ ] مصروفات تشغيلية ورأس مال، هامش ربح، صافي ربح وديون العملاء إذا فُعل البيع الآجل.
- [ ] صلاحيات مفصلة بحسب الوظيفة، المصادقة متعددة العوامل، وتدقيق التغييرات.
- [ ] نسخ احتياطي ومراقبة واسترجاع وتشفير وبيئة مرحلة اختبار.
